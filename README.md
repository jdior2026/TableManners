# Table Manners

Turn SPSS output into editable APA 7, MLA 9, conference poster or dissemination tables. Upload several outputs, make separate tables or drag and drop rows, columns and whole tables into one combined table, and compare or check outputs.

Live site: https://jdior2026.github.io/TableManners/

Files are read in your browser and aren't uploaded. The AI features and account saves only work in the Claude artifact version. Here, tables are saved in your browser only.
